O que são HTML, CSS e o Javascript

Ela servem para criar aplicações web, e cada uma tem a sua função, vou explicar o básico abaixo:

HTML

Esse é o esqueleto de uma página, aqui é onde fica títulos, textos, imagens, links e formulários

CSS

É aqui que se mexe o layout da tela, nas cores, letras. Aqui que faz deixar mais organizada

Javascript

E nesse último, ele é a parte responsiva, que dá reação como reagir a cliques e fazer contas, sem recarregar a pagina toda
